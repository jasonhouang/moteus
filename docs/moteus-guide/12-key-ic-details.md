# Moteus 关键 IC 详解

## 1. 概述

Moteus 电机控制器的核心功能依赖两个关键 IC：
- **DRV8323/DRV8353**：三相智能栅极驱动器（Texas Instruments）
- **AS5047P**：14位磁旋转绝对值编码器（ams）

这两个芯片分别负责"功率输出"和"位置反馈"，是 FOC 电机控制的基础。

## 2. DRV8323/DRV8353 三相智能栅极驱动器

### 2.1 芯片概述

DRV8323/DRV8353 是 Texas Instruments (TI) 的三相智能栅极驱动器，专为无刷直流电机 (BLDC) 控制设计。它们将 MCU 的低电压 PWM 信号转换为能驱动大功率 MOSFET 的高电压、大电流信号，同时提供全面的保护功能和电流采样。

### 2.2 核心功能

```
MCU (STM32G4)
    │ PWM 信号 (3.3V, 弱)
    ▼
┌─────────────────────────────────────────────┐
│           DRV8323/DRV8353                    │
│                                             │
│  ┌──────────────┐      ┌─────────────────┐ │
│  │  PWM输入      │─────→│  栅极驱动        │ │
│  │  (3.3V逻辑)   │      │  (电荷泵升压)    │ │
│  └──────────────┘      └────────┬────────┘ │
│                                  │           │
│                                  ▼           │
│                         6个MOSFET栅极        │
│                         (12V, 强驱动电流)    │
│                                             │
│  ┌──────────────┐      ┌─────────────────┐ │
│  │  电流采样电阻  │─────→│  CSA放大器       │ │
│  │  (mΩ级)       │      │  (5/10/20/40x)  │ │
│  └──────────────┘      └────────┬────────┘ │
│                                  │           │
│                                  ▼           │
│                         3路模拟输出          │
│                         (→STM32 ADC)        │
│                                             │
│  ┌──────────────────────────────────────┐  │
│  │  SPI接口 ←── MCU (配置/状态读取)      │  │
│  └──────────────────────────────────────┘  │
│                                             │
│  ┌──────────────────────────────────────┐  │
│  │  保护电路                             │  │
│  │  - 过流保护 (OCP)                    │  │
│  │  - 过温保护 (OTSD/OTW)               │  │
│  │  - 欠压锁定 (UVLO)                   │  │
│  │  - 栅极故障检测 (VGS/VDS)            │  │
│  │  - 短路保护                           │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
    │
    ▼
  电机 (三相 BLDC)
```

### 2.3 关键特性

| 特性 | DRV8323 | DRV8353 | 说明 |
|------|---------|---------|------|
| **工作电压** | 4.5V - 60V | 4.5V - 100V | 宽电压范围，适应不同电机 |
| **栅极驱动电流** | 最高 1A | 最高 3A | 可配置拉/灌电流 |
| **电荷泵** | 内置 | 内置 | 驱动高侧 MOSFET |
| **电流采样放大器** | 3路 | 3路 | 内置 CSA，增益可选 |
| **CSA 增益** | 5/10/20/40x | 5/10/20/40x | 通过 SPI 配置 |
| **通信接口** | SPI | SPI | 11位寄存器，最高 1MHz |
| **保护功能** | 全面 | 全面 | 过流/过温/欠压/栅极故障 |
| **封装** | QFN-32 | QFN-32 | 小封装，散热好 |
| **适用功率** | <1kW | >1kW | 根据功率选择 |

### 2.4 在 moteus 中的使用

#### 2.4.1 SPI 接口配置

DRV8323/DRV8353 通过 SPI 接口配置以下参数：

```cpp
// fw/drv8323.h
// 主要配置寄存器：
// - Register 0x02: 栅极驱动电流 (idrivep/idriven)
// - Register 0x03: 控制模式 (6xPWM / 3PWM)
// - Register 0x04: 过流保护阈值
// - Register 0x05: CSA 增益和配置
// - Register 0x06: 死区时间
```

**关键配置项**：

| 参数 | 说明 | 默认值 | 影响 |
|------|------|--------|------|
| `idrivep_hs` | 高侧栅极拉电流 | 可配置 | 开关速度、EMI |
| `idriven_hs` | 高侧栅极灌电流 | 可配置 | 开关速度、EMI |
| `idrivep_ls` | 低侧栅极拉电流 | 可配置 | 开关速度、EMI |
| `idriven_ls` | 低侧栅极灌电流 | 可配置 | 开关速度、EMI |
| `tdead` | 死区时间 | 50-200ns | 防止直通短路 |
| `ocp_level` | 过流保护阈值 | 可配置 | 保护灵敏度 |
| `csa_gain` | CSA 放大器增益 | 10x | 电流采样精度 |

#### 2.4.2 电流采样放大器 (CSA)

CSA 将电流采样电阻上的微小电压放大，供 MCU 的 ADC 读取：

```cpp
// fw/drv8323.h
constexpr float CsaSettlingTime(int csa_gain) {
  switch (csa_gain) {
    case 5:  return 0.75e-6f;  // 增益5倍，稳定时间 0.75µs
    case 10: return 1.00e-6f;  // 增益10倍，稳定时间 1.00µs
    case 20: return 1.50e-6f;  // 增益20倍，稳定时间 1.50µs
    case 40: return 2.50e-6f;  // 增益40倍，稳定时间 2.50µs
  }
  return 3.00e-6f;  // 保守回退值
}
```

**设计考虑**：
- 增益越高 → 电流采样精度越高 → 但稳定时间越长
- 稳定时间影响 PWM 最小/最大占空比
- moteus 在增益基础上加 500ns 安全裕量

#### 2.4.3 故障检测

DRV8323/DRV8353 提供全面的故障检测，通过两个状态寄存器报告：

**故障状态寄存器 1 (FSR1)**：

| 位 | 名称 | 说明 | 触发条件 |
|----|------|------|---------|
| 0 | `FAULT` | 总故障标志 | 任何故障触发 |
| 1 | `VDS_OCP` | VDS 过流 | MOSFET 漏源电压过高 |
| 2 | `GDF` | 栅极驱动故障 | 栅极驱动异常 |
| 3 | `UVLO` | 欠压锁定 | 电源电压过低 |
| 4 | `OTSD` | 过温关断 | 芯片温度 >150°C |
| 5 | `VDS_HA` | A相高侧 VDS 过流 | A相高侧 MOSFET 异常 |
| 6 | `VDS_LA` | A相低侧 VDS 过流 | A相低侧 MOSFET 异常 |
| 7 | `VDS_HB` | B相高侧 VDS 过流 | B相高侧 MOSFET 异常 |
| 8 | `VDS_LB` | B相低侧 VDS 过流 | B相低侧 MOSFET 异常 |
| 9 | `VDS_HC` | C相高侧 VDS 过流 | C相高侧 MOSFET 异常 |
| 10 | `VDS_LC` | C相低侧 VDS 过流 | C相低侧 MOSFET 异常 |

**故障状态寄存器 2 (FSR2)**：

| 位 | 名称 | 说明 | 触发条件 |
|----|------|------|---------|
| 0 | `SA_OC` | A相 CSA 过流 | A相电流采样放大器过载 |
| 1 | `SB_OC` | B相 CSA 过流 | B相电流采样放大器过载 |
| 2 | `SC_OC` | C相 CSA 过流 | C相电流采样放大器过载 |
| 3 | `OTW` | 过温警告 | 芯片温度 >120°C（未关断） |
| 4 | `CPUV` | 电荷泵欠压 | 电荷泵电压不足 |
| 5 | `VGS_HA` | A相高侧 VGS 故障 | A相高侧栅源电压异常 |
| 6 | `VGS_LA` | A相低侧 VGS 故障 | A相低侧栅源电压异常 |
| 7 | `VGS_HB` | B相高侧 VGS 故障 | B相高侧栅源电压异常 |
| 8 | `VGS_LB` | B相低侧 VGS 故障 | B相低侧栅源电压异常 |
| 9 | `VGS_HC` | C相高侧 VGS 故障 | C相高侧栅源电压异常 |
| 10 | `VGS_LC` | C相低侧 VGS 故障 | C相低侧栅源电压异常 |

**故障处理流程**：

```
故障发生
    ↓
DRV8323 FAULT 引脚拉低
    ↓
STM32 中断检测
    ↓
读取 FSR1/FSR2 寄存器
    ↓
判断故障类型
    ├─ 可恢复 (OTW, CPUV) → 记录警告，继续运行
    └─ 严重故障 (OTSD, VDS_OCP) → 立即关断，进入 kFault 状态
```

| 特性 | DRV8323 | DRV8353 | 说明 |

| **最大电压** | 60V | 100V | DRV8353 支持更高电压 |

### 2.6 为什么需要栅极驱动器

MCU 的 GPIO 无法直接驱动功率 MOSFET：

| 参数 | MCU GPIO | MOSFET 需求 | 差距 |
|------|---------|------------|------|
| 电压 | 3.3V | 10-12V | 需要升压 |
| 电流 | 25mA | 1-3A (瞬态) | 需要放大 100倍 |
| 高侧驱动 | 无 | 需要 >母线电压 | 需要电荷泵 |

DRV8323/DRV8353 的作用：
1. **电平转换**：3.3V 逻辑 → 12V 栅极驱动
2. **电流放大**：25mA → 1-3A（快速充放电 MOSFET 栅极电容）
3. **电荷泵**：生成高于母线电压的信号驱动高侧 MOSFET
4. **死区控制**：防止高/低侧 MOSFET 直通短路
5. **保护功能**：过流、过温、欠压、短路检测

## 3. AS5047P 14位磁旋转绝对值编码器

### 3.1 芯片概述

AS5047P 是 ams (Austriamicrosystems) 的 14位磁旋转位置编码器，用于检测电机转子的绝对角度位置。它通过检测永磁体产生的磁场变化，输出高精度的绝对位置信息。

### 3.2 核心功能

```
        永磁体 (贴在电机轴上)
              │
              ▼ 磁场 (径向)
┌─────────────────────────────────────────┐
│              AS5047P                     │
│                                         │
│  ┌──────────────────────────────────┐  │
│  │  霍尔传感器阵列 (4个)             │  │
│  │  - 检测磁场方向和强度             │  │
│  └──────────────────────────────────┘  │
│                    │                     │
│                    ▼                     │
│  ┌──────────────────────────────────┐  │
│  │  信号处理 + 插值算法              │  │
│  │  - 角度计算                       │  │
│  │  - 非线性补偿                     │  │
│  └──────────────────────────────────┘  │
│                    │                     │
│                    ▼                     │
│  ┌──────────────────────────────────┐  │
│  │  14位 ADC                         │  │
│  │  - 分辨率: 16384 counts/rev       │  │

│  └──────────────────────────────────┘  │
│                    │                     │

│  │  保护功能                         │  │
```

### 3.3 关键特性

| 特性 | 说明 |
|------|------|
| **分辨率** | 14位 (16384 counts/rev) |
| **精度** | ±0.1° (典型)，±0.3° (最大) |
| **最大转速** | 28000 RPM |
| **通信接口** | SPI (最高 10 MHz) |
| **工作电压** | 3.3V ±10% |
| **功耗** | 典型 10mA |
| **封装** | SSOP-8 |
| **磁场要求** | 50mT 典型 (径向磁场) |
| **工作温度** | -40°C ~ +150°C |
| **响应时间** | <1µs |

### 3.4 SPI 通信协议

AS5047P 使用简单的 SPI 协议，每次通信返回当前角度值：

**SPI 帧格式**：

```
MOSI (主机→从机):
┌─────────────────────────────────┐
│  15  14  13  12  ...  2  1  0   │
│   1   1   1   1  ...  1  1  1   │  ← 0xFFFF (任意数据)
└─────────────────────────────────┘

MISO (从机→主机):
┌─────────────────────────────────┐
│  15  14  13  12  ...  2  1  0   │
│  EF  EF  A13 A12 ... A2  A1  A0 │
└─────────────────────────────────┘

EF = 错误标志位 (2位)
  - Bit 15: 奇偶校验位 (偶校验)
  - Bit 14: 溢出/线性报警

A13-A0 = 14位角度值 (0-16383)
  - 0° = 0
  - 360° = 16383
  - 分辨率 = 360°/16384 ≈ 0.022°
```

### 3.5 在 moteus 中的使用

从代码 `fw/as5047.h` 可以看到使用方式：

```cpp
// fw/as5047.h
class AS5047 {
 public:
  using Options = Stm32Spi::Options;

  AS5047(const Options& options)
      : spi_(options) {
  }

  // 同步采样（阻塞）
  uint16_t Sample() MOTEUS_CCM_ATTRIBUTE {
    return (spi_.write(0xffff) & 0x3fff) << 2;  // 取低14位，左移2位对齐
  }

  // 异步采样：启动
  void StartSample() MOTEUS_CCM_ATTRIBUTE {
    return spi_.start_write(0xffff);
  }

  // 异步采样：完成
  uint16_t FinishSample() MOTEUS_CCM_ATTRIBUTE {
    return (spi_.finish_write() & 0x3fff);  // 取低14位
  }

 private:
  Stm32Spi spi_;
};
```

**工作流程**：

```
每个 PWM 周期 (20-60kHz)
    ↓
StartSample() → 发送 0xFFFF，启动 SPI 传输
    ↓
等待 ADC 采样完成 (其他任务)
    ↓
FinishSample() → 读取 MISO，提取 14位角度值
    ↓
MotorPosition::ISR_Update() → 更新位置/速度
    ↓
FOC 控制 → Park/Clarke 变换
```

### 3.7 板族使用

| 板族 | AS5047 CS 引脚 | SPI 共享 | 说明 |

| Family 0 (moteus r4.x) | PB11 | 与 DRV8323 共享 SCK/MISO | 原版 |

- 通过不同的 CS 引脚区分（AS5047_CS vs DRV_CS）
- 固件自动管理总线访问，无需用户干预

### 3.8 为什么需要 AS5047

FOC (磁场定向控制) 需要知道电机转子的精确角度：

| 没有编码器 | 有增量编码器 | 有 AS5047 (绝对值) |
|-----------|-------------|-------------------|
| 无法工作 | 上电需校准 | 上电即可工作 |
| 电机抖动 | 需要转动找零位 | 无需转动 |
| 效率低 | 精度一般 | 高精度 ±0.1° |

AS5047 提供：
1. **绝对位置**：上电即可知道转子位置，无需校准
2. **高精度**：14位分辨率，角度误差 <0.1°
3. **高带宽**：每个 PWM 周期都能读取角度（20-60kHz）
4. **高转速**：支持 28000 RPM，适合高速电机

### 3.9 与其他编码器对比

| 编码器类型 | 分辨率 | 绝对/增量 | 成本 | 精度 | 适用场景 |
|-----------|--------|----------|------|------|---------|
| **AS5047** | 14位 | 绝对 | 中 | ±0.1° | moteus 默认，高精度 |
| Hall 传感器 | 6状态 | 增量 | 低 | ±30° | 低成本，低精度 |
| 正交编码器 | 可变 | 增量 | 低 | 取决于线数 | 通用，需上电归零 |
| MA732 | 14位 | 绝对 | 中 | ±0.1° | AS5047 替代方案 |
| BiSS-C | 20+位 | 绝对 | 高 | ±0.01° | 超高精度 |
| 旋转变压器 | 12-16位 | 绝对 | 高 | ±0.1° | 工业级，抗干扰强 |

### 3.10 替代方案

moteus 的 `MotorPosition` 子系统支持多种编码器，AS5047 只是其中之一：

```cpp
// fw/motor_position.h
enum Type {
    kNone,         // 无编码器
    kSpi,          // SPI 编码器 (AS5047, MA732 等)
    kUart,         // UART 编码器 (BiSS-C, CUI AMT21/22 等)
    kQuadrature,   // 正交编码器
    kHall,         // Hall 传感器
    kIndex,        // 索引信号
    kSineCosine,   // 正余弦编码器
    kI2C,          // I2C 编码器
    kSensorless,   // 无传感器 (反电动势检测)
    kBissC,        // BiSS-C 协议
};
```

## 4. DRV8323 和 AS5047 的协同工作

### 4.1 控制环路

```
目标位置 (position_cmd)
    ↓
[位置环 PID]
    ↓
速度指令 (velocity_cmd)
    ↓
电流指令 (i_d_A, i_q_A)
    ↓
AS5047 读取角度 ──→ θ (转子角度)
    ↓
┌─────────────────────────────────────┐
│  FOC 控制循环 (每个 PWM 周期)        │
│                                     │
│  1. 读取三相电流 (i_a, i_b, i_c)    │
│     ← ADC (来自 DRV8323 CSA)        │
│                                     │
│  2. Clarke 变换                     │
│     (i_a, i_b, i_c) → (i_α, i_β)   │
│                                     │
│  3. Park 变换                       │
│     (i_α, i_β) + θ → (i_d, i_q)    │
│     ← θ 来自 AS5047                │
│                                     │
│  4. 电流环 PID                      │
│     (i_d_cmd - i_d) → v_d          │
│     (i_q_cmd - i_q) → v_q          │
│                                     │
│  5. 逆 Park 变换                    │
│     (v_d, v_q) + θ → (v_α, v_β)    │
│                                     │
│  6. SVPWM                           │
│     (v_α, v_β) → (duty_a, b, c)    │
│                                     │
│  7. 输出 PWM                        │
│     → DRV8323/DRV8353               │
└─────────────────────────────────────┘
    ↓
DRV8323/DRV8353 驱动 MOSFET
    ↓
电机旋转
```

### 4.2 数据流时序

```
时间轴 ──────────────────────────────────────────────→

PWM 中断 (20-60kHz)
    │
    ├─ 1. 启动 AS5047 SPI 传输 (StartSample)
    │
    ├─ 2. 等待 ADC 采样完成 (电流)
    │     ← DRV8323 CSA 输出
    │
    ├─ 3. 完成 AS5047 SPI 传输 (FinishSample)
    │     ← 读取 14位角度值
    │
    ├─ 4. FOC 计算 (Clarke → Park → PID → 逆Park → SVPWM)
    │
    └─ 5. 更新 PWM 占空比
          → DRV8323/DRV8353

主循环 (1kHz)
    │
    ├─ 读取 DRV8323 状态 (SPI)
    │     ← 检查故障标志
    │
    ├─ 更新位置/速度估算 (PLL)
    │
    └─ 发送遥测数据 (CAN-FD)
```

### 4.3 SPI 总线共享管理

AS5047 和 DRV8323 共享 SPI 总线，固件通过 CS 引脚区分：

```cpp
// 访问 AS5047
GPIO_Write(AS5047_CS, 0);     // 拉低 AS5047 CS
SPI_Transfer(0xFFFF);         // 读取角度
GPIO_Write(AS5047_CS, 1);     // 释放 AS5047 CS

// 访问 DRV8323
GPIO_Write(DRV_CS, 0);        // 拉低 DRV CS
SPI_Transfer(0x8000 | reg);   // 读写寄存器
GPIO_Write(DRV_CS, 1);        // 释放 DRV CS
```

**注意**：两个设备的 SPI 时钟频率不同：
- AS5047：最高 10 MHz（高速读取角度）
- DRV8323：最高 1 MHz（配置时低速）

## 5. 配置示例

### 5.1 DRV8323 配置

通过 CAN-FD 命令配置 DRV8323 参数：

```python
# Python 示例
import moteus

controller = moteus.Controller()

# 配置栅极驱动参数
await controller.set_config({
    'servo.pwm_rate_hz': 30000,           # PWM 频率
    'servo.drv8323_conf.idrivep_hs_ma': 500,  # 高侧拉电流
    'servo.drv8323_conf.idriven_hs_ma': 500,  # 高侧灌电流
    'servo.drv8323_conf.idrivep_ls_ma': 1000, # 低侧拉电流
    'servo.drv8323_conf.idriven_ls_ma': 1000, # 低侧灌电流
    'servo.drv8323_conf.csa_gain': 10,    # CSA 增益
    'servo.drv8323_conf.ocp_level': 3,    # 过流保护阈值
})
```

### 5.2 AS5047 配置

AS5047 无需配置，上电即可工作。但可以通过 `MotorPosition` 配置使用方式：

```python
# Python 示例
import moteus

controller = moteus.Controller()

# 配置 AS5047 作为主编码器
await controller.set_config({
    'motor_position.sources.0.type': 'spi',
    'motor_position.sources.0.cpr': 16384,      # 14位分辨率
    'motor_position.sources.0.reference': 'rotor',  # 测量转子角度
    'motor_position.sources.0.pll_filter_hz': 400.0,  # PLL 带宽
})
```

## 6. 故障排查

### 6.1 DRV8323 常见故障

| 故障代码 | 说明 | 可能原因 | 解决方法 |
|---------|------|---------|---------|
| `kOverTemperature` | 过温关断 | 散热不良、持续大电流 | 改善散热、降低电流限制 |
| `kOverCurrent` | 过流保护 | 电机短路、堵转 | 检查电机接线、降低扭矩限制 |
| `kUnderVoltage` | 欠压锁定 | 电源电压过低 | 检查电源、降低母线电压要求 |
| `kGateDriverFault` | 栅极驱动故障 | MOSFET 损坏、接线错误 | 检查 MOSFET、检查电机接线 |

### 6.2 AS5047 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 角度值不变化 | 磁铁未安装或距离太远 | 检查磁铁安装，确保距离 <2mm |
| 角度跳变 | 磁场太弱或干扰 | 检查磁铁强度，屏蔽干扰源 |
| SPI 通信失败 | 接线错误、CS 未正确控制 | 检查 SPI 接线、CS 时序 |
| 精度差 | 磁铁偏心或不对中 | 调整磁铁位置，确保同心 |
